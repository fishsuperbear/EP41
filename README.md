# EP41
用三年时间打造了智驾操作系统NOS，全面覆盖上层应用支撑框架NOS-ADF（Autonomous driving framework）、NOS-中间件、NOS-底层关键特性，形成以NOS为载体的车端、云端、桌面端、数采端的智驾应用生态底座；
NOS-ADF（Autonomous driving framework）：集应用框架、系统服务、数据&安全为一体的ADF平台架构，用框架能力实现平台业务与具体域控解耦，实现通用化[，并完美支持小算力平台]；其中应用框架覆盖感知、融合、地图、定位、规划、控制的跨异构核数据高效流转，在资源消耗低于70%的情况下实现端到端<100ms的低延迟；实现OTA、诊断、标定、热管理、平台健康、数据引擎等系统级服务，其中OTA达成自刷写100%成功率的高水准目标；安全框架实现3层安全监控、安全启动、升级验签、升级校验等一系列安全保障机制，为智驾域智能安全奠定基础；
NOS-中间件：以轻量化、硬件解耦、全面性为特征的量产级智驾中间件，全面覆盖adaptive autosar所涉及的所有业务模块，同时兼顾量产特有需求；
NOS-底层关键特性：从业务特性出发定义底层关键特性，重新自定义调度实时性、系统时钟、自刷写技术、启动、功耗、安全监控等，将智驾所需的所有关键底层依赖全量纳入NOS体系；
集成技术：建立了完整的敏捷开发流程，有完善的Daily Build与回归测试机制。单项目实现22个传感器及14个域控软件模块的大规模集成，集成频次最高daily级，且支持daily额外版本发布，软件包集成成功率98%以上；实现跨供应商跨系统的软件提交体系、自研软件自动构建自动编译体系、自动组包体系、版本说明自动生成体系，保障软件集成完全自动化流转；软件集成对接问题管理系统，实现了问题修复、问题报出与软件版本的对齐关系，实现软件与问题的100%可追溯；
价值：
全行业首次以单orinx为计算核心建筑高速领航NNP及城市领航NCP，以轻量化、强实时、低消耗为核心的全栈自研NOS智驾操作系统，以NOS-ADF（Autonomous driving framework）、NOS-中间件、NOS-底层关键特性三层框架全面覆盖智驾系统运行所依赖的应用支撑、中间件、底软，与Nvidia driveOS完美配合，最大化挖掘硬件潜力，在逻辑计算、矢量运算、带宽、时空确定性、安全保障等每个层面做到硬件效能最大化，成功将4-orinx或2-orinx完成的工作压缩进1-oinx，真正意义上以OS全系统能力实现4in1级别的极致能力；

一句话总结：以ADF、中间件、底层关键特性核心的全栈自研NOS2.0智驾操作系统，实现车端、云端、桌面端全链条量产交付，同时往涵盖全量底软的NOS3.0迈进，构建全量闭环智驾操作系统体系；
